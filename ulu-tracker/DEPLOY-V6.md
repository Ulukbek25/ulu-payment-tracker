# ULU Payment Tracker 6.0 — закрытый доступ

1. Загрузите содержимое папки `ulu-tracker` в существующую папку `ulu-tracker` GitHub (не создавайте второй уровень вложенности).
2. В Render подключите постоянную PostgreSQL-базу (Render Postgres либо другой провайдер). Укажите в Environment:
   - `DATABASE_URL` — строка подключения к базе PostgreSQL (не публикуйте её).
   - `ADMIN_USERNAME` — ваш логин администратора.
   - `ADMIN_PASSWORD` — длинный случайный пароль, минимум 14 символов. Не используйте примерные пароли.
   - сохраните прежние `DB_API_ENABLED`, `PUBLIC_URL` и другие существующие настройки.
3. Убедитесь, что Render использует `npm install` и `npm start`, корневая директория сервиса `ulu-tracker` (если это так было настроено ранее).
4. После Deploy откройте сайт, войдите под администратором и нажмите «Пользователи» в нижнем правом углу. Создавайте логины и пароли (от 12 символов). Лимитов на количество запросов или срок доступа нет.
5. ВАЖНО: старый режим без базы больше не запускается, чтобы случайно не оставить API открытым. Перед деплоем настройте PostgreSQL.

Примечания по безопасности: API поиска, QR и распознавания требуют сессии. Для публичного коммерческого запуска желательно дополнительно внедрить CSRF-защиту, аудит действий, MFA администратора и отдельные лимиты на дорогостоящие OCR-запросы. Прежняя техническая защита от слишком частых запросов в минуту сохранена; пользовательских квот нет.
